### Overview

This project develops an **intelligent dual-arm nursing robot system** that can understand its environment and interact naturally with patients in nursing scenarios.

### Role

- **Core Developer**

### Funding Source

- **National Key R&D Program**

### Contributions

- Designed and implemented embodied AI algorithms for the **Gaussian Memory Field**, enabling the robot to build a structured representation of its surroundings.
- Developed **natural language interaction** modules so that nursing staff and patients can issue high-level commands in everyday language.
- Deployed and validated the full perception–decision–interaction loop on the **DashGo** platform in real nursing-like environments.

### Techniques & Tools

- Embodied AI and world modeling (Gaussian Memory Field)
- Multimodal perception for scene understanding
- Natural language understanding and dialogue
- DashGo mobile platform and ROS-based control stack
